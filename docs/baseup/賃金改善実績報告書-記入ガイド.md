### よくある質問：Ⅲ欄（96〜102行）は「何月分」を計算するのか

**何か月分かの合計ではなく、「賃金改善実施期間の開始月」1か月分のスナップショット。**
当院の開始月は令和8年3月なので、**3月分だけ**を見る。

- （10）常勤換算数 … 令和8年3月時点の在籍職員を常勤換算した人数
- （15）改善**前**の基本給等総額 … 3月の在籍職員に、**ベアを実施しなかったと
  仮定した場合**（＝2月までの給与体系）の1か月分の基本給＋毎月の手当
- （11）改善**後**の基本給等総額 … 実際に支給した3月分の基本給＋毎月の手当
- （12）ベア実績額 … 差額（1か月分）

賞与・残業代は含めない。期間が3か月（3〜5月）になっても、この欄は
開始月（3月）時点の1か月分のままでよい。期間全体の実額を書くのは
Ⅲの「（10）全体の賃金改善の実績額」（`AB66`）の方。

## 3. ⚠️ 落とし穴

### （1）Ⅴ〜Ⅷの「常勤換算数」「改善前の基本給等総額」は計画書シート参照の数式

`AB105` `AB106` `AB114` `AB115` `AB123` `AB124` `AB132` `AB133` の8セルは、
同じブック内の **「（別添）_計画書（無床診療所及びⅡを算定する有床診療所）」シート**を
参照する数式が入っている（例: `='（別添）_計画書（無床診療所及びⅡを算定する有床診療所）'!AB78`）。

計画書シートが空のままだと**すべて 0 になり、賃金増率も 0% と表示される**。対処は2択:

1. 計画書シートに令和7年度の賃金改善計画書の値を入力する（本来の想定）
2. 数式を消して実績値を直接入力する

どちらでも数字は合うが、**数式を上書きしてよいかは東海北陸厚生局に確認**したい。
提出時に確認できない場合は 1.（計画書シートも埋める）が安全。

### （2）中間報告書との整合

作成済みの令和8年度中間報告書は次の値になっている。実績報告書と矛盾しないこと。

- 「（８）前年度からの繰越額」= **0円** → 実績報告書の `AB56`（翌年度への繰越予定額）も 0
- 賃金改善実施期間 = 令和8年6月〜7月、算定期間 = 令和8年6月〜7月

### （3）様式の取り違え

令和7年度分に新様式100（`様式100別添１`）を使わない。逆に令和8年度分に旧様式を使わない。
