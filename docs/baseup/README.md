# ベースアップ評価料 8月報告（令和8年）

> 作成日: 2026-08-26 ／ 出典と確度は本ページ末尾を参照

## 1. 結論：8月末までに出す書類は「2本」

令和8年8月31日（月）までに、**令和7年度分の実績報告**と**令和8年度分の中間報告**を
それぞれ別の様式で提出する。片方だけでは足りない。

| # | 書類 | 対象年度 | 使う様式 | 状況 |
| :-: | --- | --- | --- | --- |
| ① | 賃金改善**実績**報告書 | 令和7年度 | **旧様式**（令和6年度改定版）<br>`001730250.xlsx` の「（別添）実績報告書（診療所）」シート | **未作成** |
| ② | 賃金改善**中間**報告書 | 令和8年度 | **新様式100 別添1**（令和8年度改定版）<br>`…賃金改善中間報告書.xlsx` の「（別添１）_賃金改善実績報告書・中間報告書」シート | 作成済み |

**様式を取り違えやすいので注意。** ②の新様式100は表紙で「実績報告書／中間報告書」を
選べる作りになっているが、これは**令和8年度以降**の報告用。令和7年度分の実績報告に
新様式100を使うことはできず、旧様式を使う。

## 3. 令和7年度と令和8年度で「対象職種」の扱いが変わっている

実績報告（令和7年度・旧様式）と中間報告（令和8年度・新様式）で、
**事務職員の位置づけが違う**。同じ数字をそのまま横流ししないこと。

| 職種 | 令和7年度（旧様式） | 令和8年度（新様式100） |
| --- | --- | --- |
| 看護職員等 | 対象職員 | 対象職員 |
| 薬剤師・看護補助者・その他 | 対象職員 | 対象職員 |
| 40歳未満の勤務医師 | **対象外**職種（Ⅳ欄） | 対象職員（Ⅴ－３） |
| 事務職員 | **対象外**職種（Ⅴ欄） | 対象職員（Ⅴ－４） |

また、比較の基準月も異なる。

- 令和7年度（旧様式）: 「賃金改善する前」と「賃金改善した後」の基本給等総額を比較
- 令和8年度（新様式）: 「令和8年3月または5月時点の給与体系」を基準に比較

## 4. 進め方

1. 院内で令和7年度の数字を集める → `賃金改善実績報告書-記入ガイド.md` の「集める数字」
2. 旧様式の「（別添）実績報告書（診療所）」シートに入力
3. Ⅱ－２（9）・Ⅲ（15）のチェックボックスが「問題なし」になることを確認
4. 誓約欄に日付と開設者名を記入
5. ①②の2ファイルを `baseup-hyoukaryou23@mhlw.go.jp` へ送付
