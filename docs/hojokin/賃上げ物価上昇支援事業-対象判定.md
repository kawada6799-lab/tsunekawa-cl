# 医療機関等における賃上げ・物価上昇に対する支援事業 — 当院は対象か

## 1. 愛知県での事業名

国事業名「医療機関等における賃上げ・物価上昇に対する支援事業」は、
愛知県では **「愛知県医療機関経営支援事業（愛知県医療機関経営支援事業費補助金）」**
という名称で実施された。県のページ名で検索しても国事業名では出てこないので注意。

- 県ページ: https://www.pref.aichi.jp/soshiki/imu/iryoukikan-keieishien.html
- 申請ポータル: https://iryo-keiei.pref.aichi.jp/

## 2. ベースアップ評価料に関する要件

### 要件の中身

> 対象は、**令和8年3月1日時点でベースアップ評価料を届け出ている**有床診療所（医科・歯科）、
> 無床診療所（医科・歯科）、訪問看護ステーション及び保険薬局。

ここでいうベースアップ評価料とは、外来・在宅ベースアップ評価料（Ⅰ）、歯科外来・在宅
ベースアップ評価料、入院ベースアップ評価料（医科・歯科）、訪問看護ベースアップ評価料の
いずれか。当院は**外来・在宅ベースアップ評価料（Ⅰ）**が該当。

### Q. 「1月〜3月のベースアップ評価料を算定していないと対象外」か

**いいえ。算定月数は要件になっていない。** 基準日（令和8年3月1日）に
**届け出ているか否か**の一点で判定される。

当院の状況は要件に合致する。

| 時点 | 当院 |
| --- | --- |
| 令和8年2月末 | 外来・在宅ベースアップ評価料（Ⅰ）を届出 |
| 令和8年3月1日 | 届出済み（＝基準日クリア）／同日から算定開始 |

施設基準の届出は「受理された日の属する月の翌月から算定」（月の最初の開庁日に受理された
場合は当月）という原則があるため、**2月末受理 → 3月1日算定開始**は制度上の正常な流れ。
2月中に届け出た施設が3月から算定を始めるのは、まさにこの補助金が想定していたパターン。

実際、令和8年1月ごろ各地の医師会が「本事業の対象となるため2月中にベースアップ評価料の
届出を」と会員向けに案内していた（例: 千曲医師会「2月中にベースアップ評価料の届出をする
場合の説明資料」＝理由欄に「令和7年度医療機関等における賃上げ・物価上昇に対する支援事業の
実施」「令和8年度診療報酬改定（賃上げ対応）」を明記）。

逆に**対象外**になるのは、「令和8年3月1日時点で対象となりうる職員が在籍していたにも
かかわらず、届出を行っていなかった施設」。当院はこれに当たらない。

| 当初締切 | 令和8年7月17日 |
| 延長後の締切 | **令和8年7月31日（金）23:59** |

**本日（令和8年8月30日）時点で通常の申請受付は終了している。**

### 次にやること

1. 愛知県医療機関経営支援事業の**事務局に電話**し、
   - 期限後の申請・特例受付・追加募集の予定があるか
   - 申請しなかった施設への救済措置があるか
   を確認する（連絡先は県ページ／ポータルに掲載）。
2. 併せて県医務課にも確認する。
3. 受付終了で確定なら、令和8年度以降の後継事業の公表を待つ体制にする
   （愛知県保険医協会・愛知県医師会の会員向け通知を追う）。

## 4. その他の要件（当院の当てはめ）

| 要件 | 内容 | 当院 |
| --- | --- | --- |
| 施設要件 | 保険医療機関コードが発行済で、令和7年4月1日〜申請時点に診療報酬請求の実績があること | 2025年4月開院・請求実績あり → **該当** |
| 賃上げ要件 | 令和7年12月〜令和8年5月に基本給または毎月支払われる手当を引き上げ、令和8年6月1日以降その水準を維持・拡大 | 3月からのベアは期間内 → **該当見込み**。ただし基準は令和7年11月末時点の賃金水準なので、11月末との比較で増額になっているか要確認 |
| 実施報告 | 交付後に賃上げ支援事業実施報告書の提出が必要（他県では必須） | **要確認** |

### 補助額（他県の公表値。愛知県の額は要確認）

| 区分 | 額 |
| --- | ---: |
| 有床診療所（3床以上） | 許可病床数 × 72,000円 |
| 有床診療所（2床以下） | 1施設 150,000円 |
| **無床診療所（医科・歯科）** | **1施設 150,000円** |
| 訪問看護ステーション | 1施設 228,000円 |

⚠️ 上記の額と「実績報告を行った賃金改善の総額」を比較し、**少ない方の額**（1,000円未満
切捨て）とする運用がある。ベア総額が15万円に満たないと減額される可能性があるため、
ベースアップ評価料の実績報告（8月報告）の数字と整合を取ること。
→ `docs/baseup/README.md` 参照

## 5. 混同しやすい別の補助金

**愛知県医療機関職場環境改善等事業費補助金**（国事業名「生産性向上・職場環境整備等
支援事業」）は**別事業**。こちらの対象は「**令和7年3月31日時点**でベースアップ評価料の
届出をしている」施設であり、当院（令和8年2月届出）は**対象外**と見られる。
給付額は診療所1施設あたり18万円。
