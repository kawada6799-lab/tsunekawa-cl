## 2. 要件は「入口」と「中身」の2段構え

ここを混同したことが今回の不備の原因。**別物として扱うこと。**

| | 要件 | 内容 | 当院 |
| --- | --- | --- | --- |
| 入口 | 対象施設か | **令和8年3月1日時点でベースアップ評価料を届け出ている**こと | 令和8年2月末に届出 → **クリア** |
| 中身 | 給付金の額 | **令和7年12月〜令和8年5月の6か月間**、令和7年11月末時点の賃金水準から賃上げを実施し、令和8年6月1日以降その水準を維持・拡大 | **ここが不備** |

### 入口の要件について（当初の疑問への回答）

「1〜3月のベースアップ評価料を算定していないと対象外か」→ **入口の要件としては違う。**
基準は**令和8年3月1日時点で届け出ているか**の一点で、算定月数は問われない。
施設基準の届出は「受理された月の翌月から算定」が原則なので、2月末受理 → 3月1日算定開始は
制度上の正常な流れ。各地の医師会も「本事業の対象となるため2月中に届出を」と案内していた。

対象外になるのは「3月1日時点で対象職員が在籍していたのに届出をしていなかった施設」。
当院はこれに当たらない。

## 3. 別紙2「③月数」の不備 — 何が足りないのか

### ③月数は「算定月数」ではなく「賃上げを実施した月数」

**③月数 ＝ ベースアップ評価料を算定した月数ではない。**
対象期間（令和7年12月〜令和8年5月）のうち、実際に賃上げを実施した月数を書く欄。

算定開始が3月でも、賃上げ自体を令和7年12月分から実施していれば③月数は6と書ける。
逆に算定が3月からだからといって月数が3に縛られるわけでもない。

### 当院の入力内容（不備通知時点）

別紙2 上段「賃金改善の総額」

| 欄 | 入力値 |
| --- | ---: |
| 賃上げ（ベースアップ分）① 対象人数（常勤換算数） | 6.0人 |
| 同 ② 月額 | 3,600円 |
| 同 **③ 月数** | **3月** ← 不備 |
| 同 令和8年6月1日以降のベースアップ月額水準（直接入力） | 12,500円 |
| 同 支給額以上か（自動判定） | ○ |
| 特別手当 ①②③ | 0人／0円／0月 |
| 一時金 ①② | 0人／0円 |

職種内訳は 看護師 3.0人・事務職員 3.0人（いずれも 3,600円 × 3月）。

### 制度が認めている6か月の埋め方

| 方式 | 12月 | 1月 | 2月 | 3月 | 4月 | 5月 |
| --- | :-: | :-: | :-: | :-: | :-: | :-: |
| **原則** | ベースアップ（基本給または毎月支払われる手当の引上げ）を6か月間 | | | | | |
| **例外** | 一時金・特別手当（最大4か月分／**令和8年3月までに支給**） | | | | ベースアップ | |

例外ルールは「賃金表や給与規程等の変更に時間を要する場合」の措置。
一時金・特別手当で埋められるのは**令和7年12月分〜令和8年3月分の最大4か月分**で、
かつ**令和8年3月までに支給済み**であることが条件。4月以降はベースアップで実施し、
一時金・特別手当に相当する水準のベースアップを令和8年6月1日から行う。

当院はベースアップが3月・4月・5月の3か月分。**不足は12月・1月・2月の3か月**（要確認）。

### Q. ③月数は「6」と書かなければならないのか

**別紙2全体で対象期間6か月をカバーする必要がある。** ただし「賃上げ（ベースアップ分）の
③月数が必ず6」という意味ではない。別紙2は3行構成で、合計6か月になればよい。

| 行 | 当院の現在 | 何を書く行か |
| --- | :-: | --- |
| 賃上げ（ベースアップ分） | 3月 | ベースアップを実施した月数 |
| 特別手当 | 0月 | 令和7年12月〜令和8年3月分の最大4か月分（令和8年3月までに支給済みが条件） |
| 一時金 | 0円 | 同上 |

当院はベアが3か月なので、

- 12月〜2月に特別手当を支給していた → 特別手当の行に③月数=3を入れて 3＋3＝6 で解決
- 支給していない → ベースアップ分の③月数を6にするしかない ＝ 12月分から6か月のベア実績が必要

### Q. 「6」と書くには6か月分の実績が必要か

**必要。** ③月数は「①対象人数 × ②月額 × ③月数 ＝ ①賃金改善の総額」という掛け算の項で、
実際に支払った額を積み上げる欄。実績のない月は数えられない。
交付後の実施報告で給与台帳と突合されるため、数字だけ書き換えることはできない。

### 取りうる道は3つ

| # | 前提 | 対応 |
| :-: | --- | --- |
| A | 賃金規程を令和7年12月に遡って改定済み（実態は6か月だが記入を誤った） | ③月数を6に直して再申請。**最もきれい** |
| B | 12月〜2月に特別手当・一時金を支給済み | 特別手当の行に入力して6か月にする |
| C | どちらでもない（12月〜2月は本当に賃上げなし） | 今から遡及支給が認められるか事務局に確認するしかない |

まず給与台帳と賃金規程を見て、A・B・C のどれかを確定させる。

#### Cを選ぶ場合の損得（概算）

| 項目 | 額 |
| --- | ---: |
| 追加で支払う賃金 6.0人 × 3,600円 × 3か月 | 64,800円 |
| 社会保険料の事業主負担（約15%） | 約 9,700円 |
| 補助金の増加 129,000円 − 64,000円 | ▲65,000円 |
| **差引の持ち出し** | **約 9,500円** |

賃上げ分は補助金でほぼ全額まかなえる設計（この補助金の趣旨そのもの）。
持ち出しは社会保険料分だけで、職員には3か月分のベアが届く。

## 4. 8月31日（月）にやること

### 最優先：事務局へ電話

再申請締切（8/29 土）が経過している。まず以下を確認する。

1. 締切経過後の再申請を受け付けてもらえるか（8/29が土曜のため、週明けの取扱いがある可能性）
2. 受け付けてもらえる場合の期限と手順
3. **令和7年12月〜令和8年2月分を今から遡及支給した場合、③月数に算入できるか**（上記Cが成立するか）
4. 特別手当で埋める場合、③月数の数え方はどうなるか（上記B）
5. 賃上げ分が6か月に届かない場合、**物価上昇支援分だけでも交付対象になるか**
   （別紙2は賃上げ支援分の様式なので、物価分が別建てなら残る可能性がある）

連絡先はポータルサイト（https://iryo-keiei.pref.aichi.jp/）に掲載。

### 並行して院内で確認する（電話で話す材料）

| # | 確認事項 | 結果次第の対応 |
| :-: | --- | --- |
| 1 | 入力した「3月」がどの3か月か（給与台帳） | 3月・4月・5月なら不足は12月・1月・2月 |
| 2 | **賃金規程・賃金表の改定日**。令和7年12月に遡って改定していないか | 実態が6か月なら**単なる記入ミス**。③月数を6に直すだけで済む |
| 3 | 令和7年12月〜令和8年2月に**特別手当・一時金を支給していないか** | 支給済みなら別紙2の「特別手当」行に入力（①対象人数・②月額・③月数=3）して6か月を埋める |
| 4 | 1〜3のいずれにも当たらない場合 | 今から遡及支給が認められるか事務局に確認。一時金・特別手当は「令和8年3月までに支給」が条件のため**認められない可能性が高い** |

### ⚠️ やってはいけないこと

**実態がないのに③月数だけ6に書き換えない。** 交付後に賃上げ支援事業実施報告書の提出があり、
虚偽申請は返還・不正受給の扱いになる。医療機関の信用に直結する。
