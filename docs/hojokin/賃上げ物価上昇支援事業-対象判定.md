## 1. 制度の全体像（交付要綱で確定）

愛知県での事業名は **「愛知県医療機関経営支援事業（愛知県医療機関経営支援事業費補助金）」**。
根拠は国の「令和8年度（令和7年度からの繰越分）医療機関等における賃上げ・物価上昇に対する
支援事業実施要綱」（令和8年2月26日付け医政発0226第11号・医薬発0226第2号）。

**当院（無床診療所）に関係するのは2本立て。**

| | 事業 | 基準額（無床診療所） | 賃金要件 | 別紙2 |
| --- | --- | ---: | --- | --- |
| (1) | 賃上げ支援事業 | 1施設 **150千円** | **あり**（後述） | **必要** |
| (2) | 物価支援事業 | 1施設 **170千円** | **なし** | 不要 |

補助率はいずれも 10分の10。**合計で最大320,000円**。

### 物価支援分170,000円は今回の不備の影響を受けない

交付要綱 別表2（第5条関係）:

> （２）物価支援事業　別表１に定める基準額に補助率を乗じて得た額とする。

賃金改善額との比較がない。別表3（第6条関係）でも別紙2の提出は
「**（１）賃上げ支援事業の区分を申請する場合のみ**」とされている。
最悪でも物価支援分170,000円は残る（申請全体が保留になっていないかは要確認）。

## 3. 中身の要件 — 「6か月」の原文

### 根拠①　国の実施要綱 3.診療所等賃上げ支援事業（7）賃金改善の内容

> 原則として、本事業の支給額を活用して**令和７年12月から令和８年５月までの間**、対象職員の
> ベースアップ（基本給又は決まって毎月支払われる手当の引き上げ。以下同じ。）を実施すると
> ともに、令和８年６月１日から当該ベースアップの水準を維持又は拡大すること。
>
> ただし、賃金表や給与規程等の変更に時間を要する場合は、令和８年６月１日から対象職員の
> ベースアップを行うことを前提に、**令和７年12月から令和８年３月までの４ヶ月分の一時金又は
> 特別手当を、令和８年３月までの間に**対象職員に支給することができるが、その場合は
> **４月から５月までベースアップを実施**するとともに、支給した一時金又は特別手当に相当する
> 水準のベースアップを対象職員に対して令和８年６月１日から行うこと。

### 根拠②　別紙2【2.0超部分算定シート】Ⅵ欄の見出し

> Ⅵ　本事業の支給額を充てる期間（**最大：令和７年12月～令和８年５月の６ヶ月**）

### 根拠③　別紙2の記入例（これが決定的）

公式記入例は病院例・診療所例の2本。**どちらも合計6か月**になっている。

| 行 | 病院例 | 診療所例 |
| --- | ---: | ---: |
| 賃上げ（ベースアップ分）③月数 | 0月 | **2月** |
| 特別手当 ③月数 | **2月** | 0月 |
| 一時金 ③月数 | **4月分** | **4月分** |
| **合計** | **6か月** | **6か月** |

「2月＋4月分＝6か月」は、根拠①の但し書き（12〜3月の4か月を一時金／特別手当、
4〜5月をベースアップ）をそのまま数字にしたもの。

**結論：③月数はベースアップ分の欄だけで6にする必要はないが、
別紙2の3行（ベースアップ分・特別手当・一時金）の合計で対象期間6か月を埋める必要がある。**

### 一時金・特別手当の支給は「要件」ではない

根拠①は**原則とただし書きの2段構造**であり、ただし書きは「支給する**ことができる**」という
**選択肢**。一時金・特別手当がないこと自体は不備の理由にならない。

| | ルート | 12月 | 1月 | 2月 | 3月 | 4月 | 5月 |
| --- | --- | :-: | :-: | :-: | :-: | :-: | :-: |
| **原則** | 6か月ずっとベースアップ | ベア | ベア | ベア | ベア | ベア | ベア |
| **ただし書き** | 前半を一時金等で代替（賃金表や給与規程等の変更に時間を要する場合） | ← 一時金／特別手当 4か月分・令和8年3月までに支給 → | | | | ベア | ベア |

**必要なのは「令和7年12月〜令和8年5月の6か月について賃金改善があること」**で、
その中身がベースアップか一時金・特別手当かは問わない。

当院は**12月・1月・2月に何もない**ことが不備の中身。一時金がないことが理由ではない。

## 4. 見落としていた計上ルート2つ

### (a) 法定福利費の事業主負担分も賃金改善に含められる

実施要綱 3.(7) の注記:

> （※）賃金改善の内容には**賃金水準や基本給の引上げに伴い増加する法定福利費等の
> 事業主負担分も含む**ものとする。

社会保険料の事業主負担増加分を賃金改善の総額に算入できる。
②月額への上乗せ方法は事務局に要確認。

### (b) 2.0%超部分算定シート

令和7年度のベースアップが**令和7年3月31日時点の賃金水準**と比べて2.0%を超えていれば、
超過部分を令和7年12月〜令和8年5月の6か月分計上できる。

記入例（病院）の計算:

| 欄 | 値 |
| --- | ---: |
| Ⅰ 令和7年3月31日時点の賃金水準（月額） | 241,250円 |
| Ⅱ 令和7年度中の賃金改善額（月額） | 253,000円 |
| Ⅲ 賃金改善割合 | 4.9% |
| Ⅳ 支給額を充てられる上限月額（Ⅱ − Ⅰ×1.02） | 6,925円 |
| Ⅵ 期間 | 6月 |
| Ⅶ 対象人数 | 24.0人 |
| 賃金改善の総額（6,925 × 6 × 24.0） | 997,200円 |

**当院は2025年4月開院のため「令和7年3月31日時点」が存在しない。** 取扱いは事務局に要確認。

### 使えないもの（実施要綱 3.(7) 第3の注記）

> 定期昇給による賃金の上昇部分、診療報酬及び他の補助金等…を財源として行っている部分に
> 充てることはできない。

## 6. 8月31日（月）にやること

### 院内で先に確認（電話の材料）

まず「入力した3月がどの3か月か」を給与台帳で確定させる（3月・4月・5月なら不足は12月・1月・2月）。
そのうえで、**空いている月を埋められる可能性がある順**に確認する。

| # | 確認事項 | 結果次第の対応 |
| :-: | --- | --- |
| 1 | **賃金規程・賃金表の改定日**。令和7年12月に遡って改定していないか | 実態が6か月なら原則ルートで充足。単なる記入ミスなので③月数を6に直すだけ |
| 2 | **令和7年12月〜令和8年2月に一時金・特別手当を支給していないか**（名称は問わず、賞与とは別の臨時支給） | 支給済みなら該当行に記入して合計6か月にする（ただし書きルート） |
| 3 | 令和7年度のベースアップ率（2.0%超か） | 2.0超部分算定シートで計上できる可能性。ただし開院前の基準日の問題あり（下記） |
| 4 | 1〜3のいずれにも当たらない | 今からの遡及支給が認められるか事務局判断。条文上は厳しい（下記） |

**なぜ「今から作る」より「既に支給済みのものを探す」が先か。** 12月〜2月を今から埋める道は
条文上ほぼ塞がっている。

- 一時金・特別手当ルート → 「**令和8年3月までの間に**支給」という期限が実施要綱 3.(7)
  ただし書きにあり、今から新規に作れない
- ベースアップルート → 実施要綱 3.(8)②ア に「対象医療機関等がこれを活用して
  **令和８年３月までの間に賃金改善を実施し**、６月１日からベースアップを実施したことを
  確認する」とあり、8月に遡及支給して埋められるかは条文からは読み取れない

### ⚠️ やってはいけないこと

**実態がないのに③月数だけ6に書き換えない。**

交付要綱 第8条（決定の取消し等）:

> 知事は、補助金の交付をした場合において、事業者が次に掲げる各号のいずれかに該当する
> ときには、支援金の返還を命ずることができる。
> …（３）**虚偽又は不正の手段をもって支援金の交付を受けた場合**

実施要綱 3.(8)②エ:

> 申請内容を偽り、その他不正の手段により給付金の支給を受けたと認める場合は
> 給付金の全部の返還を求める。

また交付要綱 第10条により、申請書類と証拠書類は**交付を受けた年度の終了後5年間保存**し、
知事から求められたら提出する義務がある（第11条の調査あり）。
