# 名古屋市臨床調査個人票電子化等推進事業費補助金（令和8年度）— 対象判定と申請手順

> ✅ **名古屋市から当院に届いた案内文・申請のご案内・交付要綱・各様式の原本（写真）を確認済み。**
> 本ページの主要な記述は一次ソースに基づく。旧版（同日午前）は愛知県の事業と誤認していたため全面改訂。

## 0. 結論（令和8年10月13日時点）

**当院は対象。申請できる。** ただし**申請期限は令和8年10月30日（金）必着**で、残り約2週間。

根拠は交付要綱 第4条:

> 第4条 厚生労働省からの当該年度における難病特別対策推進事業に係る事業実施計画書の提出依頼に
> 基づき、当該年度において予め市長が行う意向調査に対し、事業の実施を表明した医療機関を
> 補助金の交付の対象とする。

当院に届いた案内文（令和8年6月19日付、名古屋市健康福祉局障害福祉部障害企画課長・
子ども青少年局子育て支援部子育て支援課長 連名）には
「**令和8年2月に貴医療機関から意向調査のご回答をいただいた**」
「意向調査にご回答いただいた医療機関が本補助金交付の対象医療機関となります」と明記されている。
**この案内が届いていること自体が、対象医療機関であることの証拠。**

### 書類の名称について（混同の整理）

| ユーザー認識 | 実際の書類 |
| --- | --- |
| 令和**9**年度 **愛知県**…補助金に係る**意向調査** | 令和**8**年度 **名古屋市**臨床調査個人票電子化等推進事業費補助金 **申請のご案内** |

- 愛知県にも同名の事業があるが、愛知県の案内は「名古屋市内の医療機関は対象外」としている。
  当院（中村区）の所管は名古屋市。愛知県の令和9年度意向調査は当院に関係ない。
- 意向調査は令和8年2月に回答済み。今回はその次のステップ（交付申請）。

### 対象外となる条件（要綱 第4条2項）— 当院はいずれも該当しないと推定

| 除外条件 | 当院 |
| --- | --- |
| (1) 既にこの要綱に基づき補助金の交付を受けた | 2025年4月開院。受給歴なし（要確認） |
| (2) 既に名古屋市小児慢性特定疾病医療意見書オンライン登録環境整備費補助金の交付を受けた | 同上。なお案内文に「難病・小慢のいずれかの補助金しか受けられない」とあり、当院は「難病」で案内されている |

### 絶対に守ること

1. **交付決定前にパソコン等を買わない。** 案内・要綱第7条2項・第1号様式の重要確認事項5・
   交付決定通知書の条件、すべてで繰り返されている。交付決定前の着手は補助対象外。
2. 10月30日（金）**必着**。郵送のみ。封筒に赤字で「**補助金申請書類在中**」。

## 2. 補助対象経費の要件（別紙）— 購入前に必ず照合

### (1) パソコン端末（オンライン用）— 全て該当すること

- メモリ 8GB 以上
- 空き容量 40GB 以上
- 対応ブラウザ: Edge／Chrome／Safari
- 必要なソフト: Acrobat Reader, **Excel**, VPN用Clientソフト
- ディスプレイ解像度: 最低 1280×1024px、推奨 1920×1080px
- プリンタ: A4 印刷可能なプリンタを利用できること
- ネットワーク: インターネット接続可（https通信）、**AWS Client VPN** を利用して外部と通信可能であること

### (2) パソコン端末（院内システム用チェックツール）— 全て該当すること

- OS: Windows10 又は Windows11
- メモリ 8GB 以上、空き容量 40GB 以上
- ディスプレイ解像度: 最低 1280×1024px、推奨 1920×1080px

### (3) プリンタ

- パソコン端末に接続し、A4 印刷が可能であること

### (4) ネットワーク環境の整備経費

- 難病・小慢データベースシステムにインターネットVPN接続ができるようネットワーク機器等を設定するための経費

### (5) 医療機関内のシステム改修経費 — 1つ以上該当

- 院内システムからオンラインでアップロードできる出力機能の追加
- 院内システムへのチェック機能の追加
- 院内システムへの臨床調査個人票の様式変更の反映

**要確認（市に電話で聞く）**: Excel（Microsoft 365 / Office）のライセンス費用が「パソコン端末の購入経費」に
含められるか。別紙は Excel を必須ソフトとしているが、経費区分の明記がない。
院内 LAN から AWS Client VPN への接続をファイアウォールが許可するかは、購入前に IT 側で確認する。

## 4. 交付申請の提出書類チェックリスト（10月30日必着分）

- [ ] **補助金交付申請書（第1号様式）**
  - 医療機関コード（「231」で始まる10桁。保険医療機関コード）
  - 医療機関名・所在地・代表者役職氏名・電話（担当者名）・E-mail
  - 勤務している難病指定医等（代表者1名）: **指定医番号・氏名** → 院長の指定医通知書で確認
  - 2 補助対象経費（**見積書の金額**）
  - 3 交付申請金額（= min(経費, 100,000) × 1/2、千円未満切捨て、上限50,000）

- [ ] **別紙（補助対象経費の要件）** — 該当する要件にチェックを入れて提出
- [ ] **見積書**（業者が発行したもの）

## 5. 交付決定の取消し・返還（第15条）

次の場合、交付決定の全部又は一部が取り消され、既に受けた補助金の返還を求められる:
(1)交付条件違反 (2)提出書類の虚偽記載 (3)補助金使用に関する不正行為 (4)その他要綱違反。
交付決定の内容に不服がある場合は、通知受領から10日以内に理由を書面で申請を取り下げられる（第9条）。
