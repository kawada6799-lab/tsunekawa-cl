# 令和9年度 愛知県臨床調査個人票電子化等推進事業費補助金（意向調査）— 対象判定

> 作成日: 2026-10-13（令和8年10月13日）／ 出典と確度は本ページ末尾を参照
> ⚠️ **愛知県・名古屋市の公式ページは本作業環境から直接取得できず（エグレス制限）、
> Web検索の要約を複数突き合わせて構成している。一次ソースの原文は院内で必ず確認すること。**

## 0. 結論（令和8年10月13日時点）

**当院は愛知県の本事業の対象外である可能性が高い（確度B）。**

理由は一つ。愛知県の案内ページ「【難病指定医の皆様へ】臨床調査個人票登録のオンライン化について」に
**「名古屋市内の医療機関は対象外です。名古屋市へお問い合わせください。」** と明記されている
（複数の検索要約で一致）。当院は名古屋市中村区所在のため、この除外に該当する。

難病指定医・指定医療機関であることは入口要件を満たすが、所在地の除外が優先する。

### 手元の書類について確認すべきこと

| 確認点 | 理由 |
| --- | --- |
| **差出人**（愛知県健康対策課か、名古屋市健康福祉局か、他） | 愛知県の意向調査は名古屋市内を対象外としているため、名古屋市内の当院に愛知県から届くこと自体が不自然 |
| **期限の表記** | 検索要約では愛知県の意向調査の回答期限は **令和8年10月2日（金）** とされている（確度C）。手元の書類は「10月30日（金）必着」。日付が一致しないため、**別の自治体・別の事業の書類の可能性**がある |
| 提出方法 | 愛知県分は Excel の意向調査票をメール送付（kenkotaisaku@pref.aichi.lg.jp、件名「令和9年度オンライン化意向調査（医療機関名）【指定難病】」）。「必着」という郵送前提の表現とも合わない |
| 当院の指定の根拠 | 指定医・指定医療機関の指定は国ではなく **都道府県または指定都市** が行う。主たる勤務先が名古屋市内の医師は名古屋市に申請する運用のため、当院の指定が名古屋市によるものか愛知県によるものかを指定通知書で確認する |

**次のアクション（推奨）**

1. 書類の差出人と宛先を確認する。
2. 差出人が愛知県なら、健康対策課（kenkotaisaku@pref.aichi.lg.jp）に
   「名古屋市内の医療機関だが対象になるか」を照会する。
3. 差出人が名古屋市なら、その書類の要件に従う（本ページの愛知県の要件は参考情報）。
   名古屋市の担当は 健康福祉局障害福祉部障害企画課 難病対策担当。
4. 名古屋市に同種の補助制度があるかは **Web検索では確認できなかった**。名古屋市に直接照会する。

## 1. 愛知県の事業の概要（検索要約ベース）

| 項目 | 内容 | 確度 |

| 事業名 | 愛知県臨床調査個人票電子化等推進事業費補助金 | A |
| 目的 | 難病指定医が勤務する医療機関が、臨床調査個人票（診断書）を国の難病・小慢データベースへオンライン登録するための業務システム改修・機器導入費用を補助 | A |
| 実施年度 | 令和4年度から実施。令和8年度分の申請受付は終了済み。令和9年度分の意向調査を実施中 | B |
| 対象 | 指定医が勤務する医療機関。**令和4〜8年度に本補助金の対象となった医療機関を除く。名古屋市内の医療機関は対象外** | B |
| 補助額 | 基準額（10万円）と対象経費の実支出額を比べて少ない方の **2分の1**（千円未満切り捨て）。上限5万円の想定 | B |

## 3. 仮に対象だった場合の注意点（他県の運用から）

- 交付決定前に着手（PC購入等）した経費は対象外とする自治体が多い（北海道・三重県）。
  愛知県の交付要綱でも同様の可能性が高い。**意向調査の段階で機器を購入しない。**
- 1医療機関につき1回限りとする自治体がある（三重県）。
- 補助は経費の2分の1、上限5万円程度。システム改修費が高額な場合でも全額は出ない。
