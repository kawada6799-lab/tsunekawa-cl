# 名古屋市臨床調査個人票電子化等推進事業費補助金 交付申請書（第1号様式）記入例

> 作成日: 2026-10-13 ／ 制度の詳細は [対象判定ページ](臨床調査個人票電子化推進事業-対象判定.md) を参照
> ⚠️ **【要記入】の箇所は院内でしか分からない値。** 下記の金額はオンライン用パソコン1台を
> 購入する想定の**仮の数字**。実際の見積書の金額に差し替えること。
> 当院は **ノートパソコン（13万円以上）** を購入予定 → 交付申請金額は上限の **50,000円** で確定。
> **提出期限: 令和8年10月30日（金）必着（郵送）**

## 2. 各欄の書き方

| 欄 | 書き方 | 根拠・注意 |
| --- | --- | --- |
| 日付 | 投函日。和暦で「令和8年10月○日」 | 10月30日必着なので、遅くとも10月27日（火）投函 |
| 医療機関コード | 様式に「２３１」が印刷済み。続く7桁を記入 | 保険医療機関コードと同じ。レセプトの「医療機関コード」で確認 |
| 医療機関名 | 正式名称 | 保険医療機関指定通知書の表記に合わせる |
| 医療機関所在地 | 様式に「名古屋市」が印刷済み。区以降を記入 | 「中村区太閤1-1-10」の正式表記（丁目・番・号）は指定通知書で確認 |
| 代表者 役職氏名 | 「院長　恒川　卓也」。押印欄はないが、様式に印の指定がない場合も代表者印を押しておくのが無難 | 開設者が医療法人の場合は「理事長」。個人開設なら「院長」 |
| 電話番号・担当者 | 代表番号と、市から問い合わせが来たとき対応する事務担当者 | 市の電話は平日日中 |
| E-mail | 令和8年2月の意向調査で回答したアドレス | 案内文に「様式等は意向調査で回答いただいたメールアドレスに送付」とある。別のアドレスにすると様式が届かない |
| 難病指定医等 | 院長の指定医番号・氏名。1名のみ | 事業完了後にこの指定医が指定医IDを申請し VPN 設定を行う義務がある |
| 2 補助対象経費 | **見積書の税込合計額**をそのまま転記 | 補助対象外の品（周辺機器・保守など）が見積に混ざる場合は、対象経費分だけを別行にした見積書を業者に依頼する |
| 3 交付申請金額 | 下記の計算式 | 要綱第6条 |
| 4 添付書類 | 添付したものにチェック。(3)はパソコン購入なら「仕様書」 | — |

### 交付申請金額の計算（要綱第6条）

```
交付申請金額 = min(補助対象経費, 100,000) × 1/2  → 1,000円未満切捨て → 上限 50,000
```

| 見積額（対象経費） | 計算 | 交付申請金額 |
| ---: | --- | ---: |
| 65,780円 | 65,780 × 1/2 = 32,890 → 切捨て | 32,000円 |
| 80,000円 | 80,000 × 1/2 | 40,000円 |
| 99,000円 | 99,000 × 1/2 = 49,500 → 切捨て | 49,000円 |
| 100,000円以上 | 100,000 × 1/2 | 50,000円 |

記入例の138,000円は10万円を超えるので上限の **50,000円**。ノートPCが13万円以上なら見積額がいくらでも申請額は50,000円。

### 別紙（補助対象経費の要件）記入例 — ノートパソコン1台を購入する場合

別紙は「チェックを入れて提出する」様式。**(1) だけ全項目に☑**を入れ、(2)〜(5) は空欄のまま。
チェックは見積書の機種の仕様書と突き合わせてから入れる（虚偽があると交付決定取消し・返還の対象）。

```
                                                              別紙
補助対象経費の要件

(1) パソコン端末（オンライン用）を購入する場合のパソコンの満たすべき要件
    （全て該当すること）
    ☑ メモリ容量　　： 8GB 以上
    ☑ 空き容量　　　： 40GB 以上
    ☑ 対応ブラウザ　： Edge／Chrome／Safari
    ☑ 必要なソフト　： Acrobat Reader, Excel, VPN 用 Client ソフト
    ☑ ディスプレイ解像度： 最低 1280×1024px、推奨 1920×1080px
    ☑ プリンタ要件　： A4 での印刷が可能なプリンタを利用できること
    ☑ ネットワーク要件： インターネット接続が可能であること（https 通信）
                        AWS Client VPN を利用して外部と通信可能であること

(2) パソコン端末（院内システム用チェックツール）を購入する場合のパソコンの満たすべき要件
    （全て該当すること）
    ☐ OS： Windows10 又は Windows11            ← 空欄
    ☐ メモリ容量 ： 8GB 以上                   ← 空欄
    ☐ 空き容量 ： 40GB 以上                    ← 空欄
    ☐ ディスプレイ解像度： …                   ← 空欄

(3) プリンタを購入する場合のプリンタの満たすべき要件
    ☐ パソコン端末に接続し、A4 での印刷が可能であること   ← 空欄（プリンタは買わない）

(4) ネットワーク環境の整備経費
    ☐ …                                        ← 空欄

(5) 医療機関内のシステム改修経費（1つ以上該当すること）
    ☐ ☐ ☐                                     ← 空欄
```

#### 各チェックの確認方法（ノートPC特有の落とし穴つき）

| 要件 | 確認方法 | ⚠️ 注意 |
| --- | --- | --- |
| メモリ 8GB 以上 | 仕様書の「メモリ」欄 | 16GB 推奨。8GB ちょうどでも要件は満たす |
| 空き容量 40GB 以上 | 仕様書の「ストレージ／SSD」欄 | 256GB 以上なら問題なし。128GB は OS と Office で埋まりやすいので避ける |
| 対応ブラウザ | Windows 11 なら Edge 標準搭載 | Chrome は後から無料で入れられる |
| 必要なソフト | 見積に **Office（Excel）が含まれる構成**にする。Acrobat Reader・VPN Client は無料で後から入れる | **「Office なし」モデルは要件を満たさない。** Home & Business または Personal のプリインストール、または Microsoft 365 を見積に含める |
| ディスプレイ解像度 最低 1280×1024 | 仕様書の「ディスプレイ」欄 | **ノートPCで最大の落とし穴。** 1366×768 の廉価モデルは縦 768px しかなく **要件を満たさない**。フルHD（1920×1080）以上のモデルを選ぶ |
| プリンタ A4 印刷可 | 院内の既存プリンタに接続できればよい | 新規購入不要。無線 LAN 経由または USB で接続できることを確認 |
| https 通信 | 院内 Wi-Fi／有線 LAN でインターネットに出られること | — |
| AWS Client VPN | 院内ルータ／ファイアウォールが **UDP 443 および TCP 443 の外向き通信**を許可していること | 電子カルテ系の閉域網しかない環境だと接続できない。購入前にネットワーク業者に確認 |

#### 見積書に含めるもの・含めないもの

| 含める（補助対象） | 含めない、または別行に分ける |
| --- | --- |
| ノートPC本体（Office 付き構成） | マウス・ケース・USB メモリなどの周辺機器（対象外の可能性） |
| Office（Excel）ライセンスが本体と別売りの場合はその分 | 延長保証・設定代行サービス（対象か不明。市に確認） |

見積額が 13 万円以上なら申請額は上限 50,000 円で頭打ちなので、
**周辺機器を別行にしても申請額は変わらない**。対象経費を明確にするため、PC 本体＋Office だけを
「補助対象経費」の行にまとめ、それ以外は別行または別見積にしてもらうと審査で差し戻されにくい。

## 3. 添付書類の揃え方

| 書類 | 要件 | 備考 |
| --- | --- | --- |
| 見積書 | **業者が発行**したもの。宛名は医療機関名 | 通販サイトのカート画面では不可の可能性。販売店に正式見積を依頼 |
| 仕様書 | メーカー仕様ページの印刷、またはカタログ | 別紙の各要件（メモリ・ストレージ・解像度・OS）が読み取れるページ |
| 別紙 | 様式に直接チェック | 原本を提出 |

## 5. 提出後

1. 市から **交付決定通知書（第2号様式）** が届くまで購入しない
2. 届いたら購入 → 領収書・納品書・設置後の写真を保管
3. 購入後30日以内または令和9年3月19日必着の早い方で **実績報告書（第7号様式）** を郵送
4. 機種変更などが必要になったら、購入前に **交付変更申請書（第4号様式）** を提出（軽微かどうかは市に電話で確認）
