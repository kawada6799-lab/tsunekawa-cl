# 名古屋市臨床調査個人票電子化等推進事業費補助金 交付申請書（第1号様式）記入例

> 作成日: 2026-10-13 ／ 制度の詳細は [対象判定ページ](臨床調査個人票電子化推進事業-対象判定.md) を参照
> ⚠️ **【要記入】の箇所は院内でしか分からない値。** 下記の金額はオンライン用パソコン1台を
> 購入する想定の**仮の数字**。実際の見積書の金額に差し替えること。

## 2. 各欄の書き方

| 欄 | 書き方 | 根拠・注意 |
| --- | --- | --- |
| 日付 | 投函日。和暦で「令和8年10月○日」 | 10月30日必着なので、遅くとも10月27日（火）投函 |
| 医療機関コード | 様式に「２３１」が印刷済み。続く7桁を記入 | 保険医療機関コードと同じ。レセプトの「医療機関コード」で確認 |
| 医療機関名 | 正式名称 | 保険医療機関指定通知書の表記に合わせる |
| 医療機関所在地 | 様式に「名古屋市」が印刷済み。区以降を記入 | 「中村区太閤1-1-10」の正式表記（丁目・番・号）は指定通知書で確認 |
| 代表者 役職氏名 | 「院長　恒川　卓也」。押印欄はないが、様式に印の指定がない場合も代表者印を押しておくのが無難 | 開設者が医療法人の場合は「理事長」。個人開設なら「院長」 |
| 電話番号・担当者 | 代表番号と、市から問い合わせが来たとき対応する事務担当者 | 市の電話は平日日中 |
| E-mail | 令和8年2月の意向調査で回答したアドレス | 案内文に「様式等は意向調査で回答いただいたメールアドレスに送付」とある。別のアドレスにすると様式が届かない |
| 難病指定医等 | 院長の指定医番号・氏名。1名のみ | 事業完了後にこの指定医が指定医IDを申請し VPN 設定を行う義務がある |
| 2 補助対象経費 | **見積書の税込合計額**をそのまま転記 | 補助対象外の品（周辺機器・保守など）が見積に混ざる場合は、対象経費分だけを別行にした見積書を業者に依頼する |
| 3 交付申請金額 | 下記の計算式 | 要綱第6条 |
| 4 添付書類 | 添付したものにチェック。(3)はパソコン購入なら「仕様書」 | — |

### 交付申請金額の計算（要綱第6条）

```
交付申請金額 = min(補助対象経費, 100,000) × 1/2  → 1,000円未満切捨て → 上限 50,000
```

| 見積額（対象経費） | 計算 | 交付申請金額 |
| ---: | --- | ---: |
| 65,780円 | 65,780 × 1/2 = 32,890 → 切捨て | 32,000円 |
| 80,000円 | 80,000 × 1/2 | 40,000円 |
| 99,000円 | 99,000 × 1/2 = 49,500 → 切捨て | 49,000円 |
| 100,000円以上 | 100,000 × 1/2 | 50,000円 |

記入例の138,000円は10万円を超えるので上限の **50,000円**。ノートPCが13万円以上なら見積額がいくらでも申請額は50,000円。

### 別紙（補助対象経費の要件）記入例 — ノートパソコン1台を購入する場合

別紙は「チェックを入れて提出する」様式。**(1) だけ全項目に☑**を入れ、(2)〜(5) は空欄のまま。
チェックは見積書の機種の仕様書と突き合わせてから入れる（虚偽があると交付決定取消し・返還の対象）。

```
                                                              別紙
補助対象経費の要件

(1) パソコン端末（オンライン用）を購入する場合のパソコンの満たすべき要件
    （全て該当すること）
    ☑ メモリ容量　　： 8GB 以上
    ☑ 空き容量　　　： 40GB 以上
    ☑ 対応ブラウザ　： Edge／Chrome／Safari
    ☑ 必要なソフト　： Acrobat Reader, Excel, VPN 用 Client ソフト
    ☑ ディスプレイ解像度： 最低 1280×1024px、推奨 1920×1080px
    ☑ プリンタ要件　： A4 での印刷が可能なプリンタを利用できること
    ☑ ネットワーク要件： インターネット接続が可能であること（https 通信）
                        AWS Client VPN を利用して外部と通信可能であること

(2) パソコン端末（院内システム用チェックツール）を購入する場合のパソコンの満たすべき要件
    （全て該当すること）
    ☐ OS： Windows10 又は Windows11            ← 空欄
    ☐ メモリ容量 ： 8GB 以上                   ← 空欄
    ☐ 空き容量 ： 40GB 以上                    ← 空欄
    ☐ ディスプレイ解像度： …                   ← 空欄

(3) プリンタを購入する場合のプリンタの満たすべき要件
    ☐ パソコン端末に接続し、A4 での印刷が可能であること   ← 空欄（プリンタは買わない）

(4) ネットワーク環境の整備経費
    ☐ …                                        ← 空欄

    ☐ ☐ ☐                                     ← 空欄
```

#### 各チェックの確認方法（ノートPC特有の落とし穴つき）

| 要件 | 確認方法 | ⚠️ 注意 |
| --- | --- | --- |
| メモリ 8GB 以上 | 仕様書の「メモリ」欄 | 16GB 推奨。8GB ちょうどでも要件は満たす |
| 空き容量 40GB 以上 | 仕様書の「ストレージ／SSD」欄 | 256GB 以上なら問題なし。128GB は OS と Office で埋まりやすいので避ける |
| 対応ブラウザ | Windows 11 なら Edge 標準搭載 | Chrome は後から無料で入れられる |
| 必要なソフト | 見積に **Office（Excel）が含まれる構成**にする。Acrobat Reader・VPN Client は無料で後から入れる | **「Office なし」モデルは要件を満たさない。** Home & Business または Personal のプリインストール、または Microsoft 365 を見積に含める |
| ディスプレイ解像度 最低 1280×1024 | 仕様書の「ディスプレイ」欄 | **ノートPCで最大の落とし穴。** 1366×768 の廉価モデルは縦 768px しかなく **要件を満たさない**。フルHD（1920×1080）以上のモデルを選ぶ |
| プリンタ A4 印刷可 | 院内の既存プリンタに接続できればよい | 新規購入不要。無線 LAN 経由または USB で接続できることを確認 |
| https 通信 | 院内 Wi-Fi／有線 LAN でインターネットに出られること | — |
| AWS Client VPN | 院内ルータ／ファイアウォールが **UDP 443 および TCP 443 の外向き通信**を許可していること | 電子カルテ系の閉域網しかない環境だと接続できない。購入前にネットワーク業者に確認 |

#### 見積書に含めるもの・含めないもの

| 含める（補助対象） | 含めない、または別行に分ける |
| --- | --- |
| ノートPC本体（Office 付き構成） | マウス・ケース・USB メモリなどの周辺機器（対象外の可能性） |
| Office（Excel）ライセンスが本体と別売りの場合はその分 | 延長保証・設定代行サービス（対象か不明。市に確認） |

見積額が 13 万円以上なら申請額は上限 50,000 円で頭打ちなので、
**周辺機器を別行にしても申請額は変わらない**。対象経費を明確にするため、PC 本体＋Office だけを
「補助対象経費」の行にまとめ、それ以外は別行または別見積にしてもらうと審査で差し戻されにくい。

## 5. 提出後

1. 市から **交付決定通知書（第2号様式）** が届くまで購入しない
2. 届いたら購入 → 領収書・納品書・設置後の写真を保管
3. 購入後30日以内または令和9年3月19日必着の早い方で **実績報告書（第7号様式）** を郵送
4. 機種変更などが必要になったら、購入前に **交付変更申請書（第4号様式）** を提出（軽微かどうかは市に電話で確認）

| 項目 | 最低（別紙） | 推奨 |
| --- | --- | --- |
| OS | — | Windows 11 **Pro**（院内 PC は Pro が管理しやすい。Home でも要件は満たす） |
| メモリ | 8GB | **16GB** |
| ストレージ | 空き 40GB | **SSD 256GB 以上**（512GB なら余裕） |
| 画面 | 1280×1024 以上 | **1920×1080（フルHD）または 1920×1200**。**1366×768 は不可** |

### 設置スペースの制約（2026-10-14 メジャー写真から読み取り）

設置予定のカウンターは **幅 約44〜45cm × 奥行 約23cm**（写真の目盛りからの読み取り。確度B。
奥行はメジャーが斜めだったため、前縁に直角に測り直すこと）。

| 画面サイズ | 本体の目安（幅×奥行） | 奥行23cmのカウンター |
| --- | --- | :-: |
| 13.3インチ | 約30.5 × 21.0cm | ○ 余裕あり |
| 14インチ（狭ベゼル） | 約31〜32.5 × 21〜22cm | ○〜△ 機種による |
| 15.6インチ | 約36 × 23.5〜24cm | ✕ 奥行が足りない |
| 16インチ | 約36 × 25cm | ✕ |

- **奥行 22cm 以下**の機種を選ぶ。15.6インチ以上は不可。
- 画面を開くとヒンジ側に数cm張り出す機種がある。**背面が壁なら 2〜3cm の余裕**を見て、13.3インチか奥行21cm台の14インチが安全。
- 幅45cmは14インチでも余裕あり。左右にマウスを置くなら13.3インチの方が楽。

### 避けるべき構成

- 画面 1366×768 のモデル（要件の縦 1024px を満たさない）
- 「Office なし」モデル
- 個人向け通販の特価品で、法人宛の見積書が出ないもの
- Microsoft 365 Basic／Personal の「1年間無料」が付くだけのモデル（Excel の永続ライセンスではない）

## 7. 見積書の取り方

要綱・案内の要件は「**業者が発行した見積書**」。宛名は医療機関名にする。

### おすすめ順

| 順 | 入手先 | 方法 | 向いている場合 |
| :-: | --- | --- | --- |
| 1 | **電子カルテ／レセコンの保守業者** | 電話またはメールで「名古屋市の補助金申請用に、別紙の要件を満たすノートPC（Office付き）の見積書が欲しい」と依頼 | **最もおすすめ。** 院内ネットワークと AWS Client VPN の接続可否を同時に確認でき、設定まで任せられる。価格はやや高いが上限5万円に影響しない |
| 2 | **メーカー法人直販サイト** | Dell・富士通 WEB MART・HP Directplus・Lenovo の法人ページで構成を選び、カートから「見積書を作成」→ PDF 保存。宛名欄に「なごやおなか恒川クリニック」 | 自分で機種を決められる。即日入手可 |
| 3 | 量販店の法人窓口（ヨドバシ・ビック・ヤマダの法人営業） | 店頭またはサイトの法人窓口で見積依頼 | 近くに店舗がある場合 |
| 4 | Amazon ビジネス 等 | 見積書 PDF を発行できるが、販売元が第三者の場合は「業者発行」として扱われるか不明 | 1〜3 が使えない場合のみ。事前に市に確認 |

### 見積書に入っているべき項目

- 宛名: なごやおなか恒川クリニック
- 発行日・見積番号・発行者（業者名・住所・連絡先・押印または電子印）
- 品名・型番・数量・単価・税込合計（**PC 本体＋Office を補助対象の行にまとめる**）
- **有効期限**: 交付決定まで数週間かかるので **60〜90 日** を依頼。短い場合は交付決定後に再見積で購入すればよい（同一機種・同一業者なら変更申請は通常不要だが、金額が変わるときは市に確認）

### 仕様書の取り方

見積書の機種の **メーカー製品ページ（仕様一覧）を印刷**して「パソコン端末等の仕様書」として添付する。
メモリ・SSD 容量・解像度・OS・Office の有無が読み取れるページであること。
業者によっては見積書と一緒に仕様書 PDF を出してくれる。

## 8. 「AWS Client VPN を利用して外部と通信可能」の判断と確認方法

> 2026-10-14 追記。難病・小慢DB の医療機関向けマニュアル（厚労省）は本環境から取得できず、
> AWS 公式ドキュメントと各自治体の案内の検索要約に基づく（確度B）。

### 8-1. 仕組み（何が必要か）

- 難病・小慢DB は、院内の PC から **AWS Client VPN**（OpenVPN ベース）でインターネット VPN を張り、
  その上でブラウザからシステムに入る方式。
- VPN 接続に必要な **接続設定情報（設定ファイル・証明書）と VPN 用 Client ソフトは、指定医 ID の発行時に配布**される
  （第1号様式 重要確認事項4）。つまり **ID 発行前は本物の接続テストができない**。
- AWS Client VPN の通信: 院内 PC → インターネット → AWS（東京リージョン）のエンドポイント。
  ポートは **443（既定）または 1194**、プロトコルは **UDP（既定）または TCP**。どちらに設定されているかは
  難病DB 側が決めるので、**外向き UDP/TCP の 443 と 1194 の両方**が通る状態にしておけば確実。
- 接続先はドメイン名（`*.clientvpn.amazonaws.com` 系）で、IP は変わる。**宛先 IP での許可はせず、ポートで許可**する。
- AWS 提供の VPN Client は **HTTP プロキシ経由の接続に非対応**。認証プロキシを強制している院内 LAN では繋がらない。

### 8-2. 申請時点（別紙にチェックを入れる根拠）の判断基準

別紙のチェックは「自己申告」。ID 発行前に実接続はできないので、**次の3点が満たせることを確認したら☑でよい**。
確認した日・相手・内容をメモに残す（実績報告や5年保存の帳簿の裏付けになる）。

| # | 確認項目 | OK の目安 | 確認方法 |
| :-: | --- | --- | --- |
| 1 | **インターネットに普通に出られる回線か** | フレッツ光等の一般 ISP 回線で、ルータ経由で Web が見られる | 院内の既存 PC で `https://www.mhlw.go.jp/` が開けばよい |
| 2 | **外向き UDP/TCP の 443・1194 を遮断していないか** | 家庭用・SOHO ルータなら既定で通る。UTM（ファイアウォール装置）や電子カルテ業者設置のルータは要確認 | ネットワーク業者／電子カルテ業者に「外向き UDP 443・TCP 443・UDP/TCP 1194 を全宛先に許可しているか」を聞く |
| 3 | **閉域網専用・プロキシ強制ではないか** | 電子カルテ用の閉域網（IP-VPN／レセプトオンライン専用線）しかない LAN は ✕。別途インターネット回線が必要 | 業者に「このセグメントからインターネットへ直接出られるか、プロキシ設定は必要か」を聞く |

**よくある NG パターン**: 電子カルテ端末と同じ閉域ネットワークに新 PC を置こうとする。
→ 患者情報を扱う電子カルテ LAN とは分離し、**インターネット側の LAN／Wi-Fi に新 PC を置く**のが安全で、
別紙の要件も満たしやすい（名古屋市の別紙も「オンライン用」PC と「院内システム用」PC を分けている）。

### 8-3. 事前にできる簡易テスト（既存の Windows PC で）

ID 発行前でも「ポートが塞がれていないか」の目安は取れる。PowerShell で:

```powershell
# TCP 443 が外に出られるか（AWS 側の任意ホストで可）
Test-NetConnection -ComputerName ec2.ap-northeast-1.amazonaws.com -Port 443
# TcpTestSucceeded : True なら TCP 443 は通る

# UDP は Test-NetConnection では確認できない。
# OpenVPN 公式クライアントを入れて UDP で接続テストできる公開サーバがあれば代用可だが、
# 確実なのはルータ／UTM の「外向き許可ルール」を業者に確認すること。
```

- `TcpTestSucceeded : False` なら、UTM・ルータで 443 が制限されているか、プロキシ必須の環境。業者に相談。
- Wi-Fi で繋ぐ予定なら、同じ Wi-Fi に繋いだ PC で試す。

### 8-4. 本番の接続確認（指定医 ID・VPN 設定情報が届いた後）

1. 購入した PC に **AWS VPN Client（AWS 提供の Windows 版クライアント）** を配布されたダウンロードサイトから入れる。
   インストールには管理者権限が要る（仮想ネットワークアダプタを追加するため）。
2. 配布された **設定ファイル（.ovpn 等）** をクライアントに取り込む（プロファイル追加）。
3. 「接続」を押して状態が **Connected** になれば VPN は OK。
4. その状態でブラウザから難病DB のログイン画面が開き、指定医 ID でログインできれば完了。
5. 繋がらないときの切り分け（AWS 公式トラブルシューティングに準拠）:

| 症状 | 原因の候補 | 対処 |
| --- | --- | --- |
| 接続がタイムアウト | ルータ／UTM が UDP または TCP の 443／1194 を遮断 | 業者に外向き許可を依頼。TCP 443 だけ許可された環境では設定ファイル側が UDP だと繋がらない |
| 証明書エラー・認証エラー | 設定ファイルの鍵・証明書が欠落／別機関のものを使用 | 配布元（難病DB 利用者お問い合わせ窓口）に再発行を依頼 |
| 名前解決エラー | DNS が引けない | PC の DNS 設定をルータ任せ（自動）に戻す |
| 接続後に DB 画面が開かない | ブラウザのプロキシ設定／セキュリティソフトの Web フィルタ | プロキシを「自動検出」または「なし」に。フィルタで `amazonaws.com` を許可 |

6. **確認できたら、接続日時・PC・担当者を記録**しておく（交付条件(1)「事業完了後に VPN 接続の環境設定を行うこと」の履行証拠）。

### 8-5. 誰に聞くか

| 内容 | 窓口 |
| --- | --- |
| 院内 LAN のルータ／UTM の外向き許可、閉域網かどうか | 院内ネットワークを設置した業者（電子カルテ業者 or 回線工事業者） |
| 難病DB の VPN 設定ファイル・クライアント・ログイン | 難病・小慢データベース 利用者お問い合わせ窓口（ID 発行通知に記載） |

## 11. 購入先は自由か — 2026-10-15

**自由。** 交付要綱・案内・様式のどこにも「メーカー直販」「指定販売店」の縛りはない。
求められている書類は次の3種類だけで、これが出せる売り手ならどこでもよい。

| 段階 | 必要書類 | 書類に入っているべきこと |
| --- | --- | --- |
| 交付申請 | **業者が発行した見積書** | 宛名（クリニック名）、発行者名・連絡先、型番、税込額 |
| 実績報告 | **領収書の写し・納品書の写し**・写真 | 宛名、日付（**交付決定日より後**）、型番、税込額 |

### 使える購入先

- メーカー直販（dynabook Direct、Dell、Lenovo 等）
- 家電量販店の店頭・法人窓口・通販（ヨドバシ、ビック、ヤマダ、ジョーシン等。価格.com 限定モデルも販売店経由で可）
- 法人向け通販（NTT-X Store、Amazon ビジネス、ミスミ等の法人カタログ）
- 電子カルテ業者・地元の PC 販売店

### 避けるべき購入先・買い方

| NG／要注意 | 理由 |
| --- | --- |
| フリマ・オークション・個人からの購入 | 「業者が発行した」見積書・領収書にならない |
| Amazon マーケットプレイスの個人出品者 | 同上。販売元が法人名の出品者に限る |
| 中古品 | 禁止規定はないが、仕様の証明と写真の審査でリスク。新品にする |
| リース・分割・サブスク | 「購入経費」でなく、年度内（3/20）に支払完了した領収書が要る |
| ポイント・クーポン大量利用 | 補助対象は**実支出額**。領収書の支払額が下がれば補助額も下がる（損ではないが申請額との差が出る） |
| 交付決定前の注文・支払 | 補助対象外。**注文日・支払日が交付決定通知の日付より後**であること |

### 見積の業者と購入先が変わる場合

同一機種・同額なら軽微な変更として扱われる可能性が高いが、要綱第10条（変更は事前に第4号様式）があるので、
**購入前に市（052-972-2632）へ電話で「見積と別の店で同じ機種を同額以下で買ってよいか」を確認**し、
日時と担当者名をメモしておく。機種や金額が変わるなら第4号様式を出す。
