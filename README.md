# tsunekawa-cl

なごやおなか恒川クリニック（名古屋市中村区・名古屋駅太閤通南口）の
IT 担当用リポジトリです。

まずはクリニックについて会話・問い合わせ対応ができる状態にするため、
公開情報を集約したナレッジベースを整備しています。

## ドキュメント

| ファイル | 内容 |
| --- | --- |
| [docs/clinic-profile.md](docs/clinic-profile.md) | クリニック基本情報（診療時間・アクセス・診療内容・料金など） |
| [docs/faq.md](docs/faq.md) | 患者さんからよくある質問と回答のドラフト |
| [docs/sources.md](docs/sources.md) | 出典一覧と情報の確度・未確認事項 |

## 重要な注意

本リポジトリの情報は **一般公開されている第三者サイトと検索結果から収集したもの** です。
公式サイト（https://nagoya-onaka.com/）へは本作業環境のネットワークポリシーにより
直接アクセスできなかったため、**院内資料での照合が完了するまでは「暫定情報」** として
扱ってください。詳細は [docs/sources.md](docs/sources.md) を参照。

患者さんへの案内に使う前に、必ず院内の正式情報で裏取りをしてください。
